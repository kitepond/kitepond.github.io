Frequently asked questions

Do I need to know how to code?

No. Open site.config.js in any text editor, change the name, phone, Zalo, email, address and prices, then upload the folder to a host. Node.js is optional (only to rebuild the CSS).

Does it really include Vietnamese – not just English?

Yes. Every page has English and Vietnamese text, with an EN / VI switch that remembers the visitor's choice. The Vietnamese is written to read naturally; still have a native speaker review your final wording.

Will Google index my Vietnamese pages?

The language switch runs in the browser, so search engines index the English text baked into the HTML. If Vietnamese organic search matters most, set language.default: "vi" and bake Vietnamese into the HTML (the docs show how), or make a separate Vietnamese copy. This is a known limitation, not a bug.

Does the booking form send me emails?

Not until you connect it. By default it validates and shows a "demo mode" panel. Connect Formspree, Netlify Forms or any custom endpoint (Make, Zapier, Google Apps Script…) in site.config.js. Submit a real test before going live.

Is there a payment gateway?

No. The tuition page has a bank-transfer / VietQR information block with copy buttons; you supply your bank details and QR image. Nothing is processed on the site.

Which hosting works?

Any static host: shared hosting/cPanel, Netlify, Cloudflare Pages, Vercel, GitHub Pages, S3. Upload the contents of the yaylish-html folder (not the zip).

Can I change colors, fonts and the logo?

Yes – colors, fonts and brand are in site.config.js; the logo and favicon are SVG files you can replace. The included fonts cover Vietnamese diacritics; if you swap fonts, pick ones with a Vietnamese subset.

Can I add a third language or remove one?

Yes. Copy assets/i18n/vi.js to a new file, translate the values and add it to language.available. The docs have a worked example.

What about the Framer files?

The Framer package is a bridge, not a finished Framer template: design tokens, three code components (language switch, tuition table, timetable) and an assembly guide. It passes a strict type-check and a render test, but has not been opened inside Framer yet. Expect to rebuild the page layouts visually.

Is the content real?

No. Teachers, parent quotes, tuition, timetable, addresses and bank details are labelled sample data. Replace them before going live (a go-live checklist is included) – never publish sample testimonials as real.

Can I use "Cambridge", "Starters / Movers / Flyers" or "IELTS" on my site?

The template uses generic level names as examples. Only use exam names, logos or "exam center / preparation" claims if your center is actually entitled to. The template is not affiliated with or endorsed by Cambridge, the IELTS owners, Zalo, Meta or VietQR/NAPAS.

Can I use one license for several client sites?

The Single site license covers one website (yours or one client's). To build for multiple clients, buy the Agency license (1.990.000 ₫).

Can I resell the template or put it on GitHub / another marketplace?

No – neither license allows reselling, redistributing or publishing the template files as a stand-alone product (including public repos and other marketplaces). Building websites for clients is fine under the right license.

What support do I get?

Email support for getting the files to work as documented (setup, config, form hookup, deploy) and bug fixes for the 1.x line, with free 1.x updates. Custom design, writing your content, hosting setup for you or building new features is not included.

What if it doesn't work?

Email kitepondstudio@proton.me within 14 days. If the files don't work as documented we'll fix it or refund you.

Why "Yaylish"?

It's a coined name (a cheerful "yay" + English) made by Kitepond Studio, and it's the template's name only – rename it to your center's brand in site.config.js. We did a public-web check for conflicting names; this is not a legal trademark clearance.

Does it work by double-clicking index.html?

Yes, it runs straight from your disk for previewing.

Will there be updates?
