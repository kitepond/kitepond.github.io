What is Yaylish?

Yaylish is a website template built with plain HTML and Tailwind CSS for kids' English centers and after-school programs in Vietnam. You get a folder of static files: edit your center's details in one file, site.config.js, and upload it to any static host. There is no framework and no database, and the template has no monthly fee; hosting and a domain (if you use one) are your own costs.

Parents mostly come to a center's website to find a phone number or Zalo, check tuition, see the timetable and ask for a trial class. The template's 7 pages cover exactly that:

What's in the zip

  • The 7 HTML pages and site.config.js (brand, colors, fonts, contact, hours, form provider, bank info)
  • Compiled, minified Tailwind CSS 3.4, plus the Tailwind source if you want to rebuild it (Node.js 18+, optional)
  • JavaScript for the language switch, schedule, tuition and form; two language files (en.js, vi.js) and three data files (schedule, tuition, levels)
  • Self-hosted fonts (Baloo 2 and Be Vietnam Pro, with a Vietnamese subset) and original SVG illustrations
  • README, DOCUMENTATION, CHANGELOG, LICENSE, an optional netlify.toml, robots.txt and sitemap.xml (replace the example.com placeholders)
  • A second, optional zip: a Framer bridge (design tokens, three code components, assembly guide) – untested inside Framer, see the notes below

Bilingual EN/VI

Every page has English and Vietnamese text and an EN / VI switch that remembers the visitor's choice. Honest note: the switch runs in the browser, so the HTML ships in English and search engines read the English text; the docs explain how to bake Vietnamese in or make a separate copy. Honest notes

  • All content in the template is sample data. Teachers, parent quotes, tuition, timetable, addresses and bank details are placeholders – replace them with real information.
  • The trial form only sends data after you connect a form provider (Formspree, Netlify Forms or your own endpoint). By default it validates input and shows a demo-mode message.
  • The language switch runs in the browser, so Vietnamese search indexing needs extra work as described in the bundled docs (make Vietnamese the baked-in default, or make a separate copy).
  • Not included: a payment gateway, a CMS or a student-management system. The VietQR block is an information panel with a QR image you supply.
  • The Framer package is a bridge for designers, not a finished Framer template, and it has not been opened inside Framer.

FAQ

Do I need to code?

No. Open site.config.js in any text editor, change the name, phone, Zalo, email and address, then upload the folder. Node.js is only needed to rebuild the CSS.

Which hosting works?

Any static host: shared hosting/cPanel, Netlify, Cloudflare Pages, Vercel, GitHub Pages and so on. An optional netlify.toml is included.

Will the trial form email me right away?

No. Connect Formspree, Netlify Forms or your own endpoint in site.config.js and send one real test before going live.

What if it doesn't work?

Email kitepondstudio@proton.me within 14 days. If the files don't work as documented, we will fix it or refund you.
