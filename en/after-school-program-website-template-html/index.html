HTML website template for after-school programs and tutoring centers

A plain HTML + Tailwind CSS template for after-school programs, tutoring centers and kids' English classes: a schedule with level filters, a tuition table, a free-trial form and floating Zalo/Messenger buttons. No framework, no database.

Who it is for

Yaylish is made for after-school programs, tutoring centers, kids' English centers and summer classes. They share the same needs, so the same 7-page structure works: programs, schedule, tuition, free-trial form, contact.

  • After-school programs and summer classes: use the Schedule and Book-a-trial pages to show sessions and take sign-ups.
  • Tutoring centers and private teachers: rename the levels to grades or subjects; edit the timetable and tuition in the data files.
  • Kids' English centers: use the full set and edit level names and prices.
  • Freelancers and agencies: build client sites for education businesses (Agency licence for several clients).

Schedule from one data file, with level chips

The timetable reads from assets/data/schedule.js. Visitors tap a level chip to see only the matching classes. You change classes, times and rooms in the data file and re-upload; no HTML editing and no database. The demo uses sample numbers.

Tuition table with a Monthly / Term / Package toggle

The Tuition page reads assets/data/tuition.js, switches between monthly, term and package prices, and calculates totals and the price per class. Currency is configurable (VND by default for Vietnamese, USD for English). A bank-transfer / VietQR block with copy buttons shows your own details and the QR image you supply; the site does not process payments.

Deploy anywhere

The template is static files, so any static host works: shared hosting/cPanel, Netlify, Cloudflare Pages, Vercel, GitHub Pages, S3. Upload the contents of the yaylish-html folder (not the zip). An optional netlify.toml is included. There is no framework to install; Node.js is only needed if you want to rebuild the CSS.

Go-live checklist (from the docs)

  • Replace brand, logo, favicon and og-cover.png; set siteUrl, robots.txt and sitemap.xml (they contain example.com placeholders)
  • Replace contact details, hours, addresses and the map placeholder
  • Replace or remove the sample teachers and sample parent quotes – never keep invented quotes live
  • Check exam or accreditation wording and keep only what is true for your center
  • Replace the timetable and tuition data, and the bank details and QR image
  • Connect the form provider and submit a real test request; add a privacy policy
  • Turn off the template-preview note and the "Sample" badges, and have a native speaker review both languages

What it does not do

  • It does not receive form submissions by itself: you connect Formspree, Netlify Forms or your own endpoint.
  • No payment gateway, CMS, parent portal or enrolment system.
  • The language switch is client-side; see the bilingual template page for the SEO limit.
  • All demo content is sample placeholder data.

FAQ

Can I use it for a tutoring center that is not about English?

Yes. Level names, text and prices are all editable, and the structure (programs, schedule, tuition, trial form, contact) is generic. You would rewrite the English and Vietnamese copy for your subject.

Is there a backend for sign-ups?

No. The form needs a provider (Formspree, Netlify Forms or a custom endpoint) that you connect in site.config.js.

Can I try it first?

Yes – the live demo runs the real template with sample data. The demo is marked noindex so its placeholder content stays out of search results.
